# simgit Homebrew Tap

Homebrew tap for [`simgit`](https://github.com/abendrothj/simgit), the `sg` CLI for disk-efficient Git worktrees.

## Install

```sh
brew tap abendrothj/tap
brew install simgit
```

The formula installs prebuilt binaries for Apple Silicon and Intel macOS, plus x86_64 and ARM64 Linux. Releases and checksums are published with [simgit releases](https://github.com/abendrothj/simgit/releases).

## Upgrade

```sh
brew update
brew upgrade simgit
```
